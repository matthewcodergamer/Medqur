# Medqur V0.8 Medication Registry Upgrade

V0.8 focuses on making medication identification useful with real packages instead of assuming that every medicine has a Medqur QR code.

## What now works

### Scan formats

Medication mode accepts the package codes already used by manufacturers:

- GS1 DataMatrix
- QR
- Code 128
- Code 39
- EAN-13
- UPC-A
- UPC-E

The parser understands common GS1 healthcare application identifiers:

- `(01)` GTIN
- `(10)` lot / batch
- `(11)` manufacture date
- `(15)` best-before date
- `(17)` expiry date
- `(21)` serial number

GTIN check digits are validated before a product identity is trusted.

### Real package fixtures from prototype testing

The local cache includes explicitly marked observed-package fixtures so the physical packages used during development can be tested end-to-end. These entries are **not** promoted to clinical approval merely because they match a package photograph.

- Neurobalin-75 — pregabalin 75 mg — observed GS1 DataMatrix GTIN `18904215101509`.
- CEFUR 500 mg — cefuroxime axetil — observed DataMatrix GTIN `18906102700512`; package also carries EAN-13 `8906102700515`.
- Mucinex DM Maximum Strength — guaifenesin 1200 mg / dextromethorphan HBr 60 mg — observed UPC `363824050287`.

The National Health Fund public benefits catalogue also lists `NEUROBALIN-75 CAP 75mg` under pregabalin. This confirms the product name is used in Jamaica, but it does not by itself authenticate the GTIN on a particular package.

## Medication resolution pipeline

`MedicationRegistryClient` resolves a scan in this order:

1. **Configured Medqur/Jamaica approved medication registry**
2. **Local observed/prototype cache**
3. **openFDA NDC Directory UPC lookup** for US-market packages
4. unresolved → pharmacist/master-data verification required

The app also offers RxNorm name search as a terminology fallback.

### Why multiple sources are needed

There is no public API currently wired into this repository that provides an authoritative Jamaica-wide GTIN-to-medicine mapping for every package sold or dispensed in Jamaica. Some medicines have GS1 DataMatrix, some have ordinary EAN/UPC codes, and imported products may be represented in foreign regulatory databases rather than a Jamaican public barcode service.

Medqur therefore separates **code parsing** from **clinical product verification**.

A barcode may be syntactically valid while the product still requires an approved medication-master match.

## Configuring an approved registry

The Flutter client has a production integration seam. Build with:

```bash
flutter build apk --release \
  --dart-define=MEDQUR_MEDICATION_API_BASE=https://medications.example.gov.jm/
```

or the equivalent web/iOS build option.

The client calls:

```text
GET /v1/medications/resolve?gtin=<GTIN>&raw=<encoded scan>
Accept: application/json
```

Suggested verified response:

```json
{
  "verified": true,
  "source": "Jamaica approved medication master",
  "product": {
    "id": "MED-12345",
    "genericName": "Pregabalin",
    "brandName": "Neurobalin-75",
    "strength": "75 mg",
    "dosageForm": "Capsule",
    "manufacturer": "Indus Life Sciences Pvt. Ltd.",
    "gtins": ["18904215101509"],
    "rxcui": "...",
    "ndc": null,
    "verified": true
  }
}
```

The public Flutter app deliberately contains no private registry API key. Production authentication should be handled with a trusted backend/session or mutually authenticated service path rather than embedding a secret in the application binary.

## Public reference services

### openFDA

For a UPC that is represented in the US NDC Directory, Medqur can query the openFDA NDC endpoint and display the returned brand/generic name, dosage form, labeler and NDC information.

This is labelled **Public reference match**, not Jamaica clinical approval.

### RxNorm

If the barcode cannot be resolved, staff can use **Search name**. Medqur queries the US National Library of Medicine RxNorm approximate-term service and displays active terminology candidates/RxCUIs.

Name search is a fallback for identification/reconciliation and does not prove the identity of a scanned package.

## Closed-loop medication administration

The existing administration flow remains:

1. scan patient wristband;
2. verify encounter;
3. scan medication package;
4. validate GTIN/check digit;
5. compare scanned product with the signed order;
6. block expired package when machine-readable expiry is available;
7. warn when lot/expiry traceability data is missing;
8. record administration only after confirmation.

A future approved product master should become a mandatory gate before administration in production.

## Next functionality to implement

1. Server-backed Jamaica medication master with approved provenance and versioning.
2. Pharmacy receiving: GTIN + lot + expiry + quantity + supplier.
3. Stock by facility/pharmacy/bin.
4. Pharmacist verification and dispense workflow.
5. Unit-dose DataMatrix generation only when the manufacturer/unit package lacks a usable code.
6. Recall search by GTIN + lot and patient exposure reporting.
7. Medication schedule/due-time engine.
8. Structured allergy and interaction service using an approved clinical knowledge base.
9. Barcode scan audit events without storing unnecessary raw identifiers.
10. Offline medication-master cache signed/versioned by the backend for network outages.
11. GS1 Verified by GS1 / enterprise API integration if the Ministry obtains the appropriate access.
12. Jamaica regulatory/procurement/NHF formulary adapters once approved machine-readable sources are available.
13. Package-photo assisted workflow only as a human-review fallback, never as the primary medication identity mechanism.
14. Pharmacy label printer support for unit-dose labels and Zebra workflows.

## Safety boundary

The observed-package fixtures, openFDA and RxNorm results are useful for development and reference. A production medication administration system must use Ministry/pharmacy-approved medication master data and clinical governance. A public database match alone must not be treated as authorization to dispense or administer a drug.
